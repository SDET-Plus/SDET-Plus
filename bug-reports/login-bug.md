# 🔐 Login Feature Bug

## 🧪 Tested
Login functionality on demo web app  

## 🐞 Bug
Login succeeds with empty password  

## 🔁 Steps to reproduce
1. Open login page  
2. Enter valid username  
3. Leave password empty  
4. Click login  

## ✅ Expected result
User should see an error message  

## ❌ Actual result
User is logged in without a password  

## ⚠️ Impact
Security issue – allows unauthorized access  

## 🧰 Tools used
Browser, manual testing
